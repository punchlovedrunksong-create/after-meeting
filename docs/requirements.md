# 요구사항 정의서

## 1. 프로젝트 개요

| 항목      | 내용                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------- |
| 프로젝트명   | after meeting (미팅 후속 업무 자동처리 Agent)                                                                               |
| 한 줄 설명  | 이미 STT로 추출된 회의 텍스트 파일을 분석해 회의 요약과 후속 할 일 목록을 제공하는 AI Agent 서비스                                                    |
| 프로젝트 목표 | TXT 형식의 회의 텍스트를 입력받아 핵심 내용을 요약하고 투두리스트를 정리함으로써 회의 후 반복적인 정리 업무와 정보 누락 가능성을 줄인다. 음성 녹음 및 STT 변환은 서비스 범위에 포함하지 않는다. |
| 개발 기간   | 2026년 11월 15일 하루                                                                                                  |
| 팀원      | 확인 필요                                                                                                             |

## 2. 해결하고자 하는 문제

| 항목            | 내용                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| 현재 문제         | 실무자는 미팅 후 녹취 텍스트를 읽고 회의 내용을 요약하거나 후속 할 일을 정리하는 데 시간을 쓴다. 이 과정에서 중요한 논의 내용이나 할 일이 누락되거나 잘못 정리될 수 있다.          |
| 사용자가 겪는 불편    | 텍스트가 길면 핵심 내용을 찾기 어렵고, 회의 내용을 다시 읽으며 요약과 할 일을 각각 정리해야 한다.                                                    |
| 이 서비스가 제공할 가치 | 이미 STT로 추출된 TXT 텍스트를 분석해 요약과 투두리스트 초안을 제공하여 사용자가 후속 업무를 빠르게 확인하고 정리하도록 돕는다. 결과의 정확성과 업무 적용 여부는 사용자가 최종 확인한다. |

## 3. 대상 사용자

| 사용자 유형       | 설명                             | 주요 상황                                           |
| ------------ | ------------------------------ | ----------------------------------------------- |
| 회의·미팅 참석 실무자 | 회의 후 논의 내용과 후속 할 일을 정리해야 하는 사람 | STT로 추출된 회의 텍스트가 있고, 핵심 내용과 할 일을 빠르게 파악하고 싶은 경우 |
| 회의 내용 공유 담당자 | 회의 결과를 본인 또는 동료에게 전달해야 하는 사람   | 긴 회의 텍스트를 검토해 요약과 후속 조치 초안을 마련해야 하는 경우          |

## 4. 입력 데이터

| 입력 데이터        | 형식     | 필수 여부 | 설명                                                                   |
| ------------- | ------ | ----- | -------------------------------------------------------------------- |
| 회의 STT 텍스트 파일 | TXT    | 필수    | 다른 도구 등을 통해 이미 음성에서 텍스트로 변환한 회의 내용. 본 서비스는 음성 녹음이나 STT 변환을 수행하지 않는다. |
| 직접 입력한 텍스트    | 일반 텍스트 | 확인 필요 | 사용자가 파일 대신 텍스트를 직접 입력하는 방식의 지원 여부는 아직 정해지지 않았다.                      |

파일 인코딩, 크기 및 텍스트 길이 제한은 정해지지 않았으므로 확인이 필요하다. 음성 파일은 현재 확정 입력에 포함하지 않는다.

## 5. 핵심 기능

| 번호 | 기능명                | 설명                                                                                 | 우선순위 |
| -- | ------------------ | ---------------------------------------------------------------------------------- | ---- |
| 1  | TXT 파일 업로드 및 내용 확인 | 이미 STT로 추출된 TXT 파일을 입력받아 분석 가능한 텍스트인지 확인한다.                                        | 높음   |
| 2  | 회의 텍스트 요약          | 입력 텍스트에서 회의의 핵심 내용을 요약해 제공한다. 요약에 포함할 세부 항목과 형식은 확인이 필요하다.                         | 높음   |
| 3  | 투두리스트 생성           | 입력 텍스트에서 후속 할 일로 볼 수 있는 내용을 정리해 목록으로 제공한다. 담당자·기한 등 텍스트에 없는 정보를 생성할지 여부는 확인이 필요하다. | 높음   |
| 4  | 분석 결과 표시           | 요약과 투두리스트를 구분해 사용자가 확인할 수 있도록 제공한다. 구체적인 화면 및 내보내기 형식은 확인이 필요하다.                   | 높음   |
| 5  | 입력·처리 오류 안내        | 파일을 읽을 수 없거나 분석에 실패한 경우, 사용자가 문제를 파악할 수 있는 안내를 제공한다.                               | 높음   |

## 6. 처리 흐름

| 순서 | 단계     | 설명                                                       |
| -- | ------ | -------------------------------------------------------- |
| 1  | 사용자 입력 | 사용자가 이미 STT로 추출된 TXT 회의 텍스트 파일을 업로드한다.                   |
| 2  | 입력 검증  | 파일 형식과 텍스트 내용의 읽기 가능 여부를 확인한다. 세부 인코딩·크기 제한은 확인 필요 사항이다. |
| 3  | AI 처리  | AI Agent가 입력된 텍스트를 분석해 회의 요약과 후속 할 일을 정리한다.              |
| 4  | 결과 정리  | 요약과 투두리스트를 구분해 사용자에게 제공할 결과로 구성한다.                       |
| 5  | 결과 출력  | 사용자가 결과를 확인한다. 저장·다운로드·공유 기능은 범위가 정해지지 않았다.              |

이 흐름에는 음성 녹음 또는 STT 변환 단계가 포함되지 않는다.

## 7. 출력 결과

| 출력 결과 | 형식             | 설명                                                               |
| ----- | -------------- | ---------------------------------------------------------------- |
| 회의 요약 | 화면에 표시되는 텍스트   | 업로드한 회의 텍스트의 핵심 내용을 압축해 보여준다. 세부 구성 및 길이는 확인 필요 사항이다.            |
| 투두리스트 | 화면에 표시되는 항목 목록 | 회의 텍스트에서 후속 할 일로 파악되는 내용을 목록으로 보여준다. 담당자·기한·우선순위 표시는 확인 필요 사항이다. |

## 8. MVP 범위

| 구분 | 기능                          | 이유                                                 |
| -- | --------------------------- | -------------------------------------------------- |
| 포함 | TXT 회의 텍스트 업로드와 읽기 가능 여부 확인 | 이미 추출된 STT 텍스트를 처리하는 서비스의 시작 입력이다.                 |
| 포함 | 텍스트 기반 회의 요약                | 프로젝트 목적의 핵심 결과다.                                   |
| 포함 | 텍스트 기반 투두리스트 생성             | 회의 후속 업무 정리라는 핵심 목적에 해당한다.                         |
| 포함 | 요약 및 투두리스트 결과 확인            | 사용자가 AI 처리 결과를 검토할 수 있어야 한다.                       |
| 제외 | 음성 녹음 및 STT 변환              | 사용자는 이미 추출된 STT 텍스트를 제공하며, 변환 기능은 요청 범위에 포함되지 않는다. |
| 제외 | 명함 정보 추출 및 후속 메일 초안 작성      | 배경에 언급된 추가 기능 후보이며, 이번 MVP 포함 여부가 확정되지 않았다.        |
| 제외 | 로그인, 배포 자동화 및 기타 부가 기능      | 현재 핵심 목적에 필요한 요구사항으로 확인되지 않았다.                     |

MVP 포함 항목은 제공된 목적에 따른 범위 초안이며, 기능별 세부 결과 형식과 데이터 취급 조건은 구현 전 확인이 필요하다.

## 요구사항·예외·수용 기준

| R-ID | 사용자 행동과 기대 결과                                       | 예외·원인                                        | 사용자 안내·복구                                                                   | 관찰 가능한 수용 기준                                                                       | T-ID |
| ---- | --------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---- |
| R-01 | 사용자가 TXT 회의 텍스트 파일을 업로드하면 서비스가 파일을 읽어 분석할 수 있어야 한다. | TXT가 아닌 파일, 빈 파일, 읽을 수 없는 인코딩 또는 파일 접근 오류    | 지원 입력이 TXT임을 안내하고, 파일 내용·형식을 확인해 다시 제공하도록 안내한다. 구체적인 오류 문구와 재시도 방식은 확인 필요다. | 정상 TXT 입력 시 파일의 텍스트가 분석 단계에 전달된다. 지원하지 않는 형식 또는 읽을 수 없는 파일은 분석 결과 대신 오류 안내가 표시된다.  | T-01 |
| R-02 | 사용자가 업로드한 텍스트의 회의 요약을 확인할 수 있어야 한다.                 | 입력 텍스트가 비어 있거나 내용이 부족해 요약을 만들기 어려움, AI 분석 오류 | 입력 내용을 확인하거나 다시 시도하도록 안내한다. AI 오류 시 오류 사실을 알리고 재시도 방법을 제공하는 방식은 확인 필요다.     | 분석 결과에 회의 요약 항목이 표시된다. 검토자는 요약이 입력 텍스트에 근거하는지 확인하며, 품질 판정 기준은 별도로 정해야 한다.          | T-02 |
| R-03 | 사용자가 업로드한 텍스트에서 후속 할 일 목록을 확인할 수 있어야 한다.            | 입력에 명확한 후속 할 일이 없음, AI 분석 오류                 | 할 일을 찾지 못한 경우와 처리 오류를 구분해 안내하는 방식은 확인 필요다.                                  | 분석 결과에 투두리스트 항목이 표시된다. 검토자는 각 항목이 입력 텍스트에 근거하는지 확인하며, 담당자·기한 등 추출 기준은 별도로 정해야 한다.  | T-03 |
| R-04 | 사용자가 요약과 투두리스트를 서로 구분해 검토할 수 있어야 한다.                | 일부 결과 생성 실패 또는 결과 표시 오류                      | 생성되지 않은 결과 항목을 구분해 안내하는 방식은 확인 필요다.                                         | 결과 화면 또는 출력에서 요약과 투두리스트가 각각 구분된 영역이나 표제로 제공된다.                                     | T-04 |
| R-05 | 사용자가 업로드 또는 분석 과정에서 문제가 생겼을 때 상태를 알 수 있어야 한다.       | 파일 형식·내용 오류, 파일 제한 초과, 분석 서비스 오류, 네트워크 오류 등  | 문제 원인을 파악할 수 있는 안내를 제공한다. 파일 제한값, 재시도 가능 여부와 상세 오류 안내는 확인 필요다.              | 정상 결과가 생성되지 않은 오류 상황에서 성공 결과로 오인되지 않도록 오류 상태가 사용자에게 표시된다. 구체적인 오류별 메시지 기준은 확인 필요다. | T-05 |

※ T-ID는 이후 테스트 시나리오와 연결하기 위한 식별자다. 이 요구사항 정의 단계에서는 코드를 실행하거나 테스트를 수행하지 않았다.
